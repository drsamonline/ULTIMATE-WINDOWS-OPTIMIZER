# Tweaks you can actually undo

Most "optimizers" are one-way doors. This one records the previous state of everything it touches and can put your machine back exactly as it was.

Reversible by design

Every registry value, service, hibernation setting and power plan is captured before it changes. Undo-All-Changes.ps1 restores the earliest recorded original — nothing else.

Real logging & backups

Logs land in %USERPROFILE%\OptimizationLogs, with per-run JSON backups written only after a change actually succeeds — so undo never "restores" something that never applied.

Eight real profiles

Daily Home, Gaming, Office, Laptop, Extreme, Godlike, Server and Streaming — each applies a genuinely different, documented tweak set, read from one source-of-truth catalog.

Verification, not vibes

Verify-System.ps1 reads the live registry and service state back and tells you what is actually applied — it never assumes a tweak worked.

Measure your own gains

Snapshot CPU load, RAM, disk and top processes before and after, then Compare-Results.ps1 diffs two real snapshots. No canned numbers, ever.

Offline & quiet

No installer, no Invoke-Expression, no scheduled tasks, no security-product changes. Zero outbound calls, zero telemetry, zero credential access.

# Elevate, snapshot, apply, verify

Four moves. The first two are the safety net; the last two are the payoff.

  1. Run the launcher as administrator

    Right-click scripts\00_Ultimate_Master.bat → Run as administrator. The launcher exits immediately if it isn't elevated.

  2. Check compatibility & take a restore point

    Option 9 runs real PASS/FAIL checks (admin, OS build, PowerShell, RAM, disk, System Restore). Option S creates a System Restore point.

  3. Snapshot a baseline, then pick a profile

    Option M saves a labeled snapshot — call it Baseline. Then choose the profile (1–8) that matches your machine.

  4. Verify, compare, or undo

    V verifies a profile was applied, R compares two snapshots for real before/after numbers, and U reverts every tracked change.

Every profile is a distinct, documented set of tweaks — and each one says what it deliberately does not do.

# Questions, answered plainly

? Will this actually make my PC faster?
It applies documented tweaks (telemetry off, GPU scheduling, power plans, visual effects and so on) that can reduce background load. But it is not a magic multiplier — results depend entirely on your hardware and workload, and no specific percentage improvement is promised anywhere in the toolkit. Use Performance-Monitor.ps1 and Compare-Results.ps1 to measure your own real before/after numbers.
? Is it safe? Can I undo everything?
Yes — reversibility is the whole point. The previous state of every registry value, service, hibernation setting and power plan is captured before the change and written to a per-run JSON backup as soon as the change succeeds. Undo-All-Changes.ps1 reads every backup and restores the earliest recorded original. It supports -WhatIf to preview, and tolerates corrupted backup files without aborting.
? Does it phone home or need the internet?
No. The toolkit makes no outbound calls, sends no telemetry and reads no credentials. There is no downloader, no Invoke-Expression, no scheduled tasks and no security-product changes. An optional dependency menu only opens official vendor download pages — it never silently runs anything.
? What's the difference between profiles?
Each profile is a genuinely different, documented set of tweaks — see the profiles table above. Gaming favours foreground apps and GPU scheduling; Server does the opposite and favours background services; Laptop is battery-aware and never disables hibernation or paging; Extreme and Godlike are desktop-only, hardware-gated, and Godlike requires typing CONFIRM because it disables Windows Search indexing.
? Re-running a profile — will it double-apply?
No. Re-running a profile is a no-op for anything that already matches — nothing is written and no backup record is added, so a second run can't record an already-tweaked value as your "original". As a second line of defence, undo de-duplicates records across all backup files by logical target and always restores the earliest original.
? What does it need to run?
Windows 10 (build 17763+) or Windows 11, PowerShell 5.1+ (built in), and administrator rights. There's no installer — it's a folder of scripts. Run Compatibility-Check.ps1 (menu 9) first to confirm your machine meets these.
? Is it open source and free?
Yes. It's released under the BSD 3-Clause licence and the source is on GitHub. Pull requests are welcome.
